# Meteorite v0.2.1

Meteorite v0.2.1 refreshes the Ballad integration used by generated projects
and locks the release toolchain to Ballad v0.3.5.

## Highlights

- Generated projects use Ballad's current control and packaging conventions.
- Release partitures share the normalized request and packaging helpers.
- The project lockfile records the Ballad v0.3.5 artifact used by the release
  workflow.

## Verification

The release tag is backed by the repository release gate and registry export
checks. The supported-target and release-contract boundaries remain those
documented in `docs/release-process.md` and the v0.1 release contract.
