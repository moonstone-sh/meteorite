# Meteorite v0.1.0

Meteorite v0.1.0 is the first stable release of the Moonstone-zig service
compiler. It compiles a Lua-declared HTTP application graph into a Zig service
and exports deployable static or hybrid release artifacts through Ballad.

## Highlights

- One normalized application graph supports static Zig-only and hybrid Zig +
  Lua release validation.
- Release exports contain a deploy-local server, manifest, static assets, and
  only the Lua runtime files/modules retained by a hybrid graph.
- Static and hybrid release checks cover HTTP TCP, native Unix-socket IPC, and
  HTTP-over-Unix-socket transports.
- Cross-target hybrid PUC Lua 5.4 releases are certified for
  `aarch64-linux-gnu` and `x86_64-linux-gnu` when Moonstone provides required
  runtime/package source provenance.
- The release gate verifies source-package contents, release reproducibility,
  copied-release execution, no host-path leakage, and target C-module rebuild
  behavior.

## Supported Contract

- Static releases: native hosts plus `aarch64-linux-gnu` and
  `x86_64-linux-gnu`.
- Hybrid releases: PUC Lua 5.4 on the same targets, provided retained runtime
  nodes have rebuildable Moonstone source provenance.
- Cross-target Lua C modules: supported only when source and rockspec payloads
  are available and the target rebuild succeeds.
- Release manifest format: `meteorite.release.v0`.

See `docs/roadmap/v0.1-ga.md` and `docs/release-compiler-contract.md` for the
complete release contract and validation rules.

## Known Boundaries

- LuaJIT cross-target hybrid releases are not supported.
- WebSockets, multipart route parsing, streaming responses, trusted-proxy
  client-IP handling, and serverless/edge adapters are explicit non-goals for
  v0.1.
- Meteorite is a compiler for service artifacts, not a drop-in general-purpose
  web framework.

## Release Verification

Before publishing a tag, run:

```bash
bash tests/release-gate.sh
bash tests/registry-export.sh
scripts/release-checksums.sh dist/registry/meteorite dist/registry/SHA256SUMS-v0.1.0.txt
```

The source package is written to `dist/registry/meteorite/`. Publish only after
recording the tag commit, artifact filenames, and checksum file alongside the
release announcement.
