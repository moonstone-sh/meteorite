# Meteorite v0.3.3

## Fixed

- **Static files larger than the request arena now serve.** `m.dir`/`m.site`
  assets were read into the route's request arena (256KB by default), so any
  larger built asset -- a bundled JS island is routinely 200KB+ -- failed with
  `OutOfMemory` (HTTP 500). The body is now read with a dedicated allocation
  sized by the build-time manifest and freed after the response. Covered by a
  409600-byte asset in `fixtures/tests/web-standards.sh`.
