# Meteorite v0.3.2

Meteorite v0.3.2 makes hybrid servers always run on the project's own Lua
runtime, and decodes path parameters before handlers see them.

## Fixes

- **The project's Lua is linked by path.** Hybrid servers used to link Lua
  with `-llua` / `-lluajit-5.1`, which also searches system directories.
  On a machine with Homebrew Lua installed, a server compiled against the
  project's Lua 5.4 headers silently linked `liblua.5.5.dylib`. Most code
  appeared to work, but native modules such as `lua-cjson` crashed the
  process (bus error or segfault on the first `ctx:json_body()`). The
  build now links `<lua-root>/lib/liblua.a` (or `libluajit-5.1.a`)
  directly, so the Lua API is exported from the server for native modules,
  and a missing runtime is a build error instead of a silent fallback. Check a
  built server with `otool -L`: only system libraries should be listed.
- **Path parameters are percent-decoded.** `c:param()`, `c.params` and
  positional handler arguments now receive `Ada Lovelace` for
  `/users/Ada%20Lovelace`, matching query values. `+` stays literal, as
  paths require. Static directory routes still validate the raw, encoded
  capture themselves, so `%2e%2e` and `%2f` remain rejected (no double decoding).

- **Namespaced Moonstone mounts.** Moonstone 0.5.9 mounts this package at
  `.moonstone/env/libexec/moonstone/meteorite`. The flat
  `libexec/meteorite` path is only an alias, absent when another package
  (e.g. `hydronium/meteorite`) shares the name. Meteorite now looks for its
  own build and CLI files under both paths (`src/cli/package_context.lua`).
  The `meteorite init` template imports the namespaced path; its previous
  `libexec/meteorite/files/meteorite` path no longer matched how current
  artifacts are mounted.

## Verification

- `tests/run-all.sh`: 35/35 (including the new `tests/package_context.lua`).
- `tests/build-api-native.sh`: passes against the namespaced layout.
- `zig test zig/server/context_request.zig`: capture decoding.
- `fixtures/tests/web-standards.sh` passes end to end. It previously crashed
  at the JSON body tests on machines with a system Lua. It includes the new
  `/params/lua-text/:name` decoding checks.
